# 水墨输入法 · GlassKey IME

水墨输入法是一款面向 Android 平台的输入法应用。它与其他主流输入法最根本的区别在于架构取向：**所有计算都在本地完成，键盘不做任何数据回传**。拼音、手写、语音三类输入方式，连同支撑它们的词典、识别模型、语料数据，全部随安装包离线分发——安装之后，无论是否联网，输入法的每一项功能都可以完整使用。

> 下载：见 [Releases](https://github.com/mohuanmo/shuimo/releases) 页面的 APK（arm64-v8a / x86_64）。

## 隐私设计

在整个输入过程里，键盘没有埋点、没有统计 SDK、没有任何形式的遥测。应用持有 `INTERNET` 权限的原因只有一个：词库订阅。当用户主动添加一个订阅链接时，键盘才会向该地址发起下载，用于更新自定义词库；除此之外，没有第二个联网场景。用户的击键内容、输入习惯、学习数据一律保存在设备本地的 SQLite 与文件中，没有云端账号，没有同步通道。

在学习机制上，键盘遵循了几条业界已经验证过的隐私底线：

- 密码框、电话号码等敏感输入框会被自动识别，其中的内容不进入任何学习通道——不记录用词习惯、不参与联想建模、不生成纠错记忆；
- 学习功能本身提供总开关，可以随时整体关闭；
- 所有已经产生的学习数据，包括用词搭配、联系人卡片、语音纠错映射、短期热词，都可以在设置中一键清空。

用户对「键盘记住了什么」拥有完整的知情权和处置权。

## 输入能力

- **拼音输入**：26 键全键盘与九宫格双布局。核心是一个 C++ 实现的整句引擎：音节切分、双数组 Trie 词典检索、Beam 整句解码，支持模糊音（z/zh、an/ang 等）、`xi'an` 这类歧义切分、连续拼音自动上屏；九宫格针对真实使用做了多轮打磨，支持首字母简拼、多音字全拼索引与词组优先的分词策略。内置中文 35 万+、英文 12 万+ 词条，完全离线可用。
- **语音输入**：内置 sherpa-onnx Zipformer 中文语音识别模型（int8 量化），识别全程在本机推理，不上传音频。说话过程中文字实时流式显示在候选栏，说完直接上屏；上屏后的短时间内若用手动输入修正识别结果，键盘会以词为单位记录「原词 → 修正词」的映射，下次遇到同样的识别错误自动替换。整套修正学习带有多重防护，避免把整句重写、口误删除这类正常操作误学成错误的替换规则。
- **手写输入**（建设中，如实说明）：手写模块目前只有很基础的实现逻辑，模型也尚未达到可正常使用的状态——识别结果的覆盖面和准确率都存在明显问题，部分字无论怎么写都无法正确识别，整体距离可用还有相当距离。这一模块是当前明确的建设方向，但在它完成之前，请将手写功能视为占位，不建议作为实际输入手段依赖。
- **悬浮键盘**：键盘可以脱离输入框位置，以悬浮窗形式停留在屏幕任意位置，自由拖动，宽度可在 20%～95% 之间调节，位置会被记住，下次唤起自动恢复。适合单手操作、大屏手机，以及需要边看别处边打字的场景。
- **独立数字小键盘**：参考电脑键盘 NumPad 的形态单独设计，通过键盘上的切换键进入和退出，不占用主键盘空间，适合频繁输入数字的场合。
- **词库订阅**：除内置词库外，支持以链接为单位管理词库订阅——每个订阅可查看上次更新时间与提供的词条数，支持手动「立即更新」，也可设定自动更新间隔（每小时到每周，或自定义分钟数）。订阅来源完全由用户自己决定，键盘只负责按链接下载。

## 汉化之外的一点说明

键盘界面为磨砂玻璃视觉风格，由自绘 View 实现，无第三方 UI 依赖；工程为单模块结构，C++17 核心引擎（词典、解码、用户模型）与 Kotlin IME 层通过 JNI 桥接，源码完整开放在仓库中，欢迎自行编译与审阅——对于一个以隐私为卖点的键盘来说，「代码可查」本身就是承诺的一部分。

## 当前状态

拼音与英文输入、语音输入、悬浮键盘、数字键盘、词库订阅均已可用；手写输入尚未完成，是已知的主要短板；语音识别受限于本机 int8 模型的体积与算力取舍，准确率与云端大模型方案存在差距，在嘈杂环境或语速较快时错字会增多，更适合「先出初稿、再做微调」的用法。Releases 页面提供 APK 下载。

## 工程结构

```
app/
  src/main/cpp/        C++17 核心引擎（词典、Beam 解码、用户模型）与 JNI 桥接
  src/main/java/       Kotlin IME 层：输入法服务、键盘视图、候选栏、
                       语音、手写、悬浮窗、剪贴板、设置与词库管理
  src/main/assets/     离线词典（.gkdt）、ASR 模型、手写模型、语料
  src/main/jniLibs/    onnxruntime JNI 库（arm64-v8a / x86_64）
  src/test/            JVM 单元测试
models/hwr/            手写模型与校验清单
tools/dictbuilder/     词典构建脚本与种子词表
tools/diag/            输入诊断工具
```

- 语言：Kotlin + C++17，`minSdk 26` / `targetSdk 34`
- 构建：Gradle（Groovy DSL）+ CMake 3.22.1 + NDK 27，JDK 17
- UI：自绘 View，无 androidx 运行时依赖

## 构建说明

源码包不包含以下第三方二进制（体积与再分发许可原因，需自行准备）：

- `app/libs/sherpa-onnx-1.13.7.aar`（sherpa-onnx 官方发布）
- `app/libs/onnxruntime-java.jar`（onnxruntime Java API）

以及常规的 Gradle Wrapper 与 Android SDK/NDK 环境。将它们放入对应位置后，即可用 `./gradlew :app:assembleRelease` 构建。
