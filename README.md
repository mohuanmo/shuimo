# 水墨输入法 · GlassKey IME

> 先说清楚：这输入法不完美，绝大多数代码是 AI 写的，边用边改，遇到问题很正常。
>
> 装好之后得你自己去系统设置里把「麦克风」和「显示在其他应用上层」两个权限打开，语音和悬浮键盘才干活；不打开也能正常打字。依赖方面挑得比较干净，运行时没有要商业授权的库，想再分发的话不用太担心授权这块。

水墨输入法是个 Android 输入法，做的其实是件挺笨的事：所有计算都放在手机本地，键盘不往外传东西。拼音、语音这些功能，连同词典和模型，全都塞在安装包里，装完断了网也照常用。手写那块还没弄好，下面单独说。

APK 在 [Releases](https://github.com/mohuanmo/shuimo/releases) 页面，arm64-v8a 架构。

## 隐私

键盘没埋点，没接统计 SDK，也没有任何形式的遥测。要 INTERNET 权限只为一件事：词库订阅。你自己加了个订阅链接，它才会去那个地址下载词库，除此之外不联网。你打的字、输入习惯、学到的词，都存在本机的 SQLite 和文件里，没有账号，也没有同步通道。

学习这块守了几条线：密码框、电话号码这类输入框会被认出来，里面的内容不学——不记用词，不参与联想，也不拿去做纠错；学习功能本身有个总开关，随时能关；已经学出来的东西，包括用词搭配、联系人卡片、语音纠错映射、短期热词，设置里可以一键清空。键盘记住了什么，你自己能看见，也能删。

## 输入

**拼音**：26 键和九宫格两套布局。核心是 C++ 写的整句引擎，做音节切分、双数组 Trie 查词、Beam 搜索解码。模糊音（z/zh、an/ang 这些）支持，`xi'an` 这种能切开，拼音连着打也能自动上屏。九宫格改过不少轮，首字母简拼、多音字全拼、词组优先都做了。词库中文 35 万条、英文 12 万条，全离线。

**语音**：sherpa-onnx 的 Zipformer 中文模型，int8 量化，在本机跑，音频不上传。说话的时候候选栏跟着出字，说完直接上屏。上屏后短时间内你手动改了识别结果，它会按词记下「原来识别成什么 → 你改成了什么」，下次碰到同样的错就自动换。这套学习加了几道保险，免得把整句重写、删口误这种正常操作也当成纠错规则学进去。

**手写**：基本没做成。代码和模型文件都还在，但这条路一直没走通。模型试了好几回都加载不起来；训练的时候也出了岔子，训出来的模型特别认死理，稍微不合它的意就罢工，正常手写根本喂不进去。现在面板里还能蹦出字的，是早先内置的一套 $P 点云模板匹配，只认数字 0-9 和十来个最简单的字，这显然算不上手写。所以就把手写当成一个空着的坑，别指望它认字；往后要么重新训模型，要么换个法子。

**悬浮键盘**：键盘可以从输入框位置挪出来，变成悬浮窗停在屏幕任意地方，随便拖，宽度 20%～95% 可调，位置会记住，下次弹出来还在原处。单手用、大屏手机、边看别处边打字的时候挺方便。

**数字小键盘**：照着电脑 NumPad 的样子单独做了一套，用键盘上的切换键进出，不占主键盘的地方。经常填数字的时候好用。

**词库订阅**：除了内置词库，可以按链接管理订阅。每个订阅能看上次更新时间、给了多少词条，能手动点「立即更新」，也能设自动更新的间隔（一小时到一周，或者自己填分钟数）。订阅地址你自己定，键盘只负责照着下载。

## 题外话

界面是磨砂玻璃那套，View 自己画的，没用第三方 UI 库。工程就一个模块，C++17 的引擎（词典、解码、用户模型）通过 JNI 接 Kotlin 那层。源码都在仓库里，想编译想翻都行——一个主打隐私的键盘，代码能被人查到，比嘴上说多少句都管用。

## 现在能用到什么程度

拼音、英文、语音、悬浮键盘、数字键盘、词库订阅都能用。手写基本没影儿，只剩代码和一个加载不起来的模型，是眼下最大的短板。语音受限于手机本地跑的 int8 模型，跟云端大模型比还是有差距，嘈杂的地方或者说得快，错字会多，适合先出个草稿再改。

## 目录

```
app/                    Android 模块
  src/main/cpp/         JNI 桥（gk_jni.cpp）+ CMake
  src/main/java/        Kotlin 这边：输入法服务、键盘视图、候选栏、
                        语音、手写、悬浮窗、剪贴板、设置和词库管理
  src/main/assets/      离线词典（.gkdt）、ASR 模型、语料
                        （手写模型文件在，但加载不起来）
  src/main/jniLibs/     onnxruntime JNI 库（arm64-v8a）
  libs/                 sherpa-onnx AAR、onnxruntime Java API
  src/test/             JVM 单元测试
core/                   C++17 引擎，和平台无关
  include/glasskey/     C ABI 头文件
  src/                  词典（DAT）、音节切分、Beam 解码、拉丁引擎、用户模型
  tests/                宿主单元测试
models/hwr/             手写模型和校验清单（当前加载不起来，功能不可用）
tools/dictbuilder/      词典构建脚本和种子词表
tools/diag/             输入诊断工具
```

- Kotlin + C++17，minSdk 26，targetSdk 34
- AGP 8.5.2、Gradle 8.9、Kotlin 2.0.20、NDK 27.0.12077973、CMake 3.22.1、JDK 17
- 界面自己画，没有 androidx 运行时依赖
- 第三方组件列在 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)

## 编译

源码包里 Gradle Wrapper、sherpa-onnx AAR、onnxruntime Java API 都带着，装好 JDK 17 和 Android SDK / NDK 就能编：

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew :app:assembleRelease
```

release 没配签名，要分发的话自己准备 keystore。
